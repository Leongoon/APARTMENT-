# 인수인계 노트 — 등촌동 복층 3D 가구배치

마지막 갱신: 2026-10-11 · 브랜치 `claude/3d-furniture-placement-sim-2qy63b`

## 목표와 범위

- 사용자가 입주할 등촌동 복층 세대 1층 평면도(이미지)를 3D로 만들고, 가구를 자유롭게 배치해 보는 프로그램.
- 요구사항: 안드로이드 동작 · 가구 색상/크기 입력 후 배치 · 소파/TV/침대(슈퍼싱글·퀸·킹·라지킹)/테이블/탁상형 테이블 등 · 다양한 각도 · [회전] 버튼으로 3D 회전 · [가구 배치] 버튼 · 배치 중 가구 회전 · [결정]으로 설치.

## 완료한 작업

| 요구사항 | 구현 위치 |
| --- | --- |
| 평면도 3D화 | `src/planData.js`(데이터), `src/plan3d.js`(장면) |
| 안드로이드 | `android/`(WebView 래퍼, Java) + `.github/workflows/android-apk.yml`(APK 자동 빌드 → `apk-latest` 릴리스) |
| 색상·크기 입력 | `src/main.js` `openProps()` — 색상 팔레트+직접 선택, 가로/깊이/높이(cm), 규격 프리셋 |
| 가구 종류 | `src/catalog.js` 48종 (침대 5종 규격 포함) |
| 다양한 각도 | `src/viewer.js` — 3D/평면/1인칭, 벽 높이 3단계, 외벽 자동 컷어웨이 |
| 회전 버튼 / 가구 배치 버튼 | 하단 도구 막대 `회전`·`이동`·`가구 배치` |
| 배치 중 회전·[결정] | 배치 패널: ±15°/±90°, 슬라이더, `시점 회전` 전환, `결정`/`취소` |

추가로 넣은 것: 겹침 경고(벽·설비·가구·문 열림 반경), 거리(cm) 표시, 벽 자석, TV 등 자동 올림, 배치안 A/B/C, 도면 크기 보정, 화면 저장, 내보내기/불러오기, 다크 모드, 가로 화면.

## 주요 결정과 이유

1. **웹(three.js) + 안드로이드 WebView 래퍼**: 하나의 코드로 APK·브라우저·claude.ai Artifact 를 모두 지원. 빌드 결과는 단일 HTML(`dist/index.html`, 약 620KB)이라 오프라인 APK에 그대로 내장.
2. **도면 축척 추정**: 이미지에 치수가 없어 전용면적 50.16㎡를 1층 외곽선에 맞춰 역산(약 86px=1m → 실내 6.36×7.38m). 앱에서 실측값으로 보정 가능하게 함.
3. **원본 평면도 이미지는 커밋하지 않음**: 공개 저장소이고 네이버 워터마크가 있는 이미지라서.
4. **APK 서명 키 커밋**(`android/app/debug.keystore`, 비밀번호 `android`): 매 빌드 같은 키여야 업데이트 설치 시 저장된 배치(localStorage)가 유지됨. 개인 사이드로드용.
5. **이 개발 환경에서는 dl.google.com 이 막혀 Android SDK 를 받을 수 없음** → APK 빌드 검증은 GitHub Actions 에서만 가능.
